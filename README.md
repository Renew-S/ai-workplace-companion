# AI Workplace Companion

Build a modern, responsive SaaS web app called AI Workplace Productivity Assistant.

The app helps professionals complete workplace tasks using AI-generated, context-aware responses rather than generic placeholder content.

Main Features

1. Smart Email Generator

User enters what the email should be about.

Generate a complete professional email using AI.

Tone options: Formal, Friendly, Persuasive, Direct, Urgent.

Include editable AI output.

Add buttons for Generate, Regenerate, Copy, and Clear.

2. AI Task Planner

User enters their tasks and optionally selects Daily or Weekly planning.

AI creates a prioritized schedule.

Prioritize tasks based on urgency and importance.

Display tasks clearly with priority, suggested time, and status.

Allow users to edit, delete, and mark tasks as complete.

3. AI Workplace Chatbot

Create an interactive workplace AI assistant.

Users can ask questions or request help with workplace tasks.

Generate useful, contextual AI responses.

Include a clean chat interface with message history.

Allow users to clear the conversation.

Dashboard & UI

Create a polished SaaS dashboard with:

Left sidebar navigation.

Dashboard/Home page.

Email Generator page.

Task Planner page.

AI Chat page.

Responsive mobile navigation.

Modern cards, forms, buttons, tabs, and empty states.

Clean professional typography and spacing.

Design

Use a dove gray + pistachio green color palette with a clean, minimal, professional appearance.

The interface should feel like a modern AI productivity SaaS platform: elegant, simple, intuitive, and responsive across desktop, tablet, and mobile.

Technical Requirements

Frontend only — no backend.

No login, signup, or registration.

Store temporary user data locally where useful.

Use real AI-generated responses rather than hardcoded generic responses.

Structure AI prompts carefully for consistent, useful workplace outputs.

Make all AI-generated results editable.

Include loading states, error handling, and helpful empty states.

Responsible AI

Add a visible Responsible AI disclaimer stating that AI-generated content may contain errors and users should review outputs for accuracy, privacy, confidentiality, and appropriateness before using them professionally.

Focus on making the app feel fully functional, polished, modern, and production-quality, while keeping the implementation simple enough for a frontend-only application.
